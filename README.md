# User Similarity Based Movie Recommendations

This project demonstrates the use of user similarity in movie recommendations compared to other recommendation systems. In addition to personal recommendations, performance is also assessed for different methods.

## Data
Download the **MovieLens Latest Full Dataset** from [GroupLens](https://grouplens.org/datasets/movielens/latest/).

1. Create a folder named `Downloads` in the project directory.  
2. Place all `.csv` files from the dataset into that folder.

## Interactive App
After installing the packages from requirements.txt, the app can by ran by opening a terminal in the folder and running: "streamlit run app.py" or "python -m streamlit run app.py"

In some cases it might be necessary to install the streamlit package manually.
